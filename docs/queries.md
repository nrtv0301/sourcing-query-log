## 使い方

1. 検索を試したら `data/queries.csv` に1行足す
2. `verdict` は 効いた / 空振り / 未着手 のいずれか
3. **`why` は必ず書く。**なぜ効いた／効かなかったかが、次の検索式を決める
4. `found_good` には、その検索から◎判定に至った人数を入れる

**件数が多いことは、効いたことを意味しません。**
94件出ても◎が2人なら、それは絞り込みが甘いということです。
